2. Reset / Back to Zero Query
When you're done testing and want to wipe all this dummy data away, run this query. It will only delete patients and appointments, meaning your Admin/Staff accounts and your Doctors will stay perfectly safe!

sql

-- 1. Delete all appointments
DELETE FROM appointments;
-- 2. Reset the appointments ID counter back to 1
ALTER TABLE appointments AUTO_INCREMENT = 1;
-- 3. Delete ONLY users who are patients (keeps admin/staff safe)
DELETE FROM users WHERE role = 'patient';
-- 4. Reset the users ID counter (it will safely resume from the highest remaining ID, e.g. the Admin ID)
ALTER TABLE users AUTO_INCREMENT = 1;
